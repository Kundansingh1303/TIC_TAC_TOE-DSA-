# 🎮 Tic Tac Toe AI using Minimax Algorithm

A console-based **Tic Tac Toe** game developed in **C++** that uses the **Minimax Algorithm** to create an unbeatable AI opponent. This project demonstrates concepts of **Data Structures & Algorithms (DSA)**, **Recursion**, and **Game Theory**.

---

## 📖 Project Overview

The objective of this project is to implement an intelligent Tic Tac Toe game where a human player competes against an AI. The AI uses the **Minimax Algorithm** to evaluate all possible game states and always chooses the best possible move.

This project was developed as part of learning **Data Structures and Algorithms** and understanding how AI decision-making works in turn-based games.

## 🧠 How the Minimax Algorithm Works

The Minimax Algorithm is a decision-making algorithm used in two-player games.

- The AI evaluates every possible move.
- It assumes the opponent always plays the best possible move.
- It chooses the move that maximizes its own score while minimizing the opponent's chances of winning.
- As a result, the AI never loses if implemented correctly.
